# Testers

## The testers' page

[TESTERS.md](../TESTERS.md), at the root of the repository, is for the people testing the training. On GitHub it's at https://github.com/ameijers/PrometheanCCaaSTraining/blob/main/TESTERS.md (once the repository is public). It covers:
- **This test round**: the training's address, the class code, the end date, and how to start;
- getting started;
- in a class or on your own, and where the work is kept;
- what to try (the labs, a first route, the tabs);
- sending feedback;
- their data;
- what's good to know.

**For each test round:**
1. Create the class.
2. Fill in **This test round**: the class code and the end date.
3. Commit and push. Testers see it on GitHub straight away; no deploy needed.

When the app changes, check the page still matches: the button names, the welcome choices, the feedback kinds and the limits.

## The note to send

The text below goes to testers by email or chat. The class code and the end date are on the testers' page, so the note stays the same each round.

> **Subject: Help us test the Contact Center training**
>
> Hi,
>
> Thank you for helping test Promethean CCaaS Training. It teaches Dynamics 365 Contact Center hands-on, in a simulation: no Dynamics 365 environment, no real phone numbers, no account needed.
>
> **Start here:** https://github.com/ameijers/PrometheanCCaaSTraining/blob/main/TESTERS.md
> At the top you'll find the link to the training and your class code. Below that: how to get in, what to try and how to send feedback. It takes two minutes to read.
>
> **What we'd like:**
> - about an hour, before the date on that page;
> - labs 1 to 4 at least, and a call on the Phone and Agent tabs;
> - feedback on anything, big or small, with the **Feedback** button at the top of the training. Send it from the screen where it happened.
>
> A computer works best. If you can, try Firefox or Safari: we've tested those the least.
>
> Thanks!

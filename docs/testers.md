# Testers

## The testers' guide

The page [public/testers.html](../public/testers.html), served at `/testers.html`, is for the people testing the training. It covers:
- getting started;
- in a class or on your own, and where the work is kept;
- what to try (the labs, a first route, the tabs);
- sending feedback;
- their data;
- what's good to know.

It's a static page without scripts, so it fits the site's Content Security Policy. The build copies it next to the app (webpack.config.js). The welcome screen links to it.

When the app changes, check the guide still matches: the button names, the welcome choices, the feedback kinds and the limits.

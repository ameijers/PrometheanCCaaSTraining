# Admin center reference screenshots

Screenshots of the real Copilot Service admin center, used only to check the training's simulated pages
(menu paths, page names, field labels, layout). They are never committed or shipped: this folder is in
.gitignore, apart from this file. Take them in the demo environment, never in the development environment.

Save each one with the number and name below (PNG), for example `05-queue-page.png`.

1. `01-sitemap` — the site map, with Customer support expanded.
2. `02-queues` — Customer support › Queues (the page with Advanced queues and Manage).
3. `03-advanced-queues` — the list after selecting Manage.
4. `04-create-a-queue` — the Create a queue dialog after selecting New.
5. `05-queue-page` — an existing voice queue's page, scrolled so users, Assignment method, Overflow management and Operation hours show (two screenshots are fine: 05a, 05b).
6. `06-add-users` — the Add users flyout on a queue.
7. `07-workstreams` — Customer support › Workstreams (the list).
8. `08-workstream-page` — a voice workstream's page: Routing rules, Work distribution, Fallback queue, and anything else on it (05-style a/b if long).
9. `09-decision-list` — Route to queues › the Decision list of a workstream that has rules.
10. `10-create-rule` — the Create route to queue rule dialog with a condition being added (the condition builder opened on a context variable, and the Route to queues list opened).
